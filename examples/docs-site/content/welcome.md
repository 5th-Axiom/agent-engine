## 核心特点

- **现成的聊天界面**：在网站里放上聊天图标或完整聊天页，支持换肤、品牌色和电脑／手机布局。
- **连接你的模型与业务**：使用自己的模型配置，把查询库存、检索文档等业务能力接成助手的工具。
- **对话可以持续**：保存会话和历史，用户下次回来可以继续聊，也能随时开始新对话。
- **过程可以查看**：查看回答状态、工具执行和模型用量，开发者可通过 Debug 页面排查问题。

## 产品形态

根据你想做的事情选择产品，点击右侧入口即可打开完整接入示例。

| 产品 | 一键开始使用 |
| --- | --- |
| **前端 SDK** 为你的网站提供聊天图标、嵌入式聊天页和可组合的界面组件。 | [使用前端 SDK](/docs/frontend/) 复制挂载示例，连接你的后端聊天接口。 |
| **后端 SDK** 在你的 Node 服务中调用模型，管理会话并执行获准的业务工具。 | [使用后端 SDK](/docs/sdk/) 跟着示例创建会话，发送消息并取得回答。 |

**它们可以一起用，也可以从后端单独开始。** 前端 SDK 负责聊天界面，需要连接运行后端 SDK 的服务；已有自己的界面时，可以只接后端 SDK。

当前为源码开发版。首次接入请先按[安装与包的选择](/docs/installation/)生成并安装所需包，再进入对应示例。

## 先体验，再接入

点击右下角的文档助手，即可体验由前端 SDK 和后端 SDK 共同提供的聊天。试着问“前端 SDK 能做什么？”或“我的项目应该从哪里接入？”，再打开“当前会话”和“工具”查看本次会话的信息。

需要了解更多功能边界时，查看[支持范围与使用规则](/docs/rules/)；需要在本机运行完整示例时，查看[本地示例](/docs/quickstart/)。
