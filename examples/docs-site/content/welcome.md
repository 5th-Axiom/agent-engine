Agent Engine 让你的产品拥有 **AI 对话、业务工具调用和可恢复的会话**。你负责模型、业务数据和用户权限，引擎负责运行过程。

## 先完成一件事

| 你的目标 | 从哪里开始 |
| --- | --- |
| 在后端创建对话，拿到第一条回答 | [创建对话](/docs/sdk/) |
| 已有聊天后端，在网站放一个聊天窗口 | [嵌入界面](/docs/frontend/) |
| 前后端一起接入，包含登录和会话保存 | [完整示例](/docs/integration/) |

第一次使用，先看[环境准备](/docs/installation/)。每条路线都提供可导出的完整示例。

## 按场景继续

- [发送图片与读取历史图片](/docs/images/)：上传、预览、看图回答和继续追问。
- [调用业务工具](/docs/tools/)：把已有业务方法交给助手使用。
- [调用 Skill](/docs/skills/)：复用一套工作步骤。
- [检索知识](/docs/knowledge/)与[读取记忆](/docs/memory/)：使用已授权的数据。
- [展示进度与停止](/docs/events/)和[接入 Debug](/docs/debug/)：了解一次运行发生了什么。

每个场景都说明前置条件、接入代码、预期结果和排错方式。需要查某个参数时，再打开 [API 参考](/docs/api/)。

## 产品如何交付

目前可使用源码和本地生成的 SDK 开发包。CLI、压缩包、安装包的产品形态仍待确定，发布后会在[交付方式](/docs/installation/#交付方式)补充对应入口。文档的场景组织不依赖某一种交付形式。
