Agent Engine 是嵌入你自己产品的 Agent 开发工具。它负责调用模型、保存会话、执行获准的业务工具，并提供执行记录；你决定用户从哪里进入，以及助手可以访问什么。

这份手册围绕一个目标：**让你的项目用上 Agent，并知道接入之后怎样使用和扩展。** 不需要先完成仓库的本地演示。

## 选择接入方式

| 你要实现什么                              | 从哪里开始                                  | 你需要接入的部分                                        |
| ----------------------------------------- | ------------------------------------------- | ------------------------------------------------------- |
| 管理后台右下角有一个图标，点击就能聊天    | [前端 SDK 接入](/docs/frontend/)            | chat-ui + chat-core；后端提供 chat-server 接口和 Engine |
| 在一个页面中放入完整聊天区                | [前端 SDK 接入](/docs/frontend/)            | 使用 mountChatPage，复用相同后端                        |
| 保留已有聊天 UI，或在后台任务中调用 Agent | [后端 SDK 接入](/docs/sdk/)                 | 只使用 @agent-runtime/sdk，自己组织接口与展示           |
| 想完全定制聊天体验，同时复用对话状态管理  | [组件与对话管理](/docs/frontend-customize/) | 按需使用 chat-core、原子组件或业务组件                  |

**前端 SDK 和后端 SDK 是两种接入起点。** 选择前端 SDK 可以直接获得现成界面，仍需连接服务端；选择后端 SDK 可以只调用 Agent 能力，无需安装前端包。两者也可以组合使用，本网站右下角的助手就是组合接入的例子。

## 两条链路分别怎样工作

使用现成聊天界面：

```text
你的管理后台
  └─ 前端 SDK：图标 / 聊天页 / 主题
       └─ 你的 Node 后端：chat-server + 已有登录系统
            └─ 后端 SDK：Engine → 模型 / 业务工具 / PostgreSQL
```

直接调用后端能力：

```text
你的页面、业务接口或定时任务
  └─ 你的 Node 服务：调用后端 SDK
       └─ Engine → 模型 / 业务工具 / PostgreSQL
  └─ 将回答或执行状态用于你自己的业务
```

前端只发送用户问题和助手 ID。模型地址、API Key、工具权限及会话数据由服务器管理。这里没有默认代管的模型服务，接入方需要准备模型访问权限和 PostgreSQL。
