## 首轮站点验证（历史记录）

本机默认真实 Provider + 独立 PostgreSQL 数据库已通过三轮连续问答：密钥配置问题实际执行 docs.search；普通聊天未调用检索；分布式调度与公共 npm 发布状态的回答符合当前项目资料。页面刷新后，三轮历史仍可恢复。默认回答使用适合当前 IM 的纯文本。

## 限制

- 本地启动器没有公网发布，生产身份、持久限流、日级额度及运维仍由正式宿主负责。
- 文档检索按关键词和中文双字片段排序，无外部向量数据库；引用来自可见资料，但不自动证明答案语义正确。
- 当前 IM SDK 按纯文本显示回答；有效来源链接在文档页面末尾提供。
- 接入教程需随公开 API 变更维护；六份主要示例共用 TypeScript 源文件，接口参考和示例配置两份手册直接同步。宿主鉴权和业务实现由接入方验收。
- 没有改动 SDK 核心，未重跑与本站无关的全量 PostgreSQL 崩溃矩阵；本站新增行为单独验证。
