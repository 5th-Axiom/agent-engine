# Agent Engine 官方文档站

## 用户与任务

面向第一次将 Agent Engine 接入自己产品的中文开发者。主线是两条并列接入路线：使用前端 SDK 获得现成 IM，或直接使用后端 SDK 获得 Agent 能力。每条路线说明安装、完整调用、配置、接入后的日常使用和扩展；本地源码演示只作为附录。

## 已确认

- 用户要求可操作的文档站，直接实现后看实际页面调整（code-led）。
- 默认进入 AI 模式，使用自己的前端 SDK 页面式对话框并接入检索工具；顶部可切换传统文档站模式，文章内保留 icon 助手。允许普通聊天，项目事实依据资料回答。
- 聊天内容左侧展示对话列表；界面提供“当前会话”和“工具”的查看入口，传统模式悬浮助手与 AI 页面共同使用通用 SDK 实现。
- 内容要适合初次接入者，兼顾电脑与手机，说明代码放在哪里、哪些是 SDK API、哪些业务函数由接入方实现，以及验证结果。
- 用户明确修正方向：重点为“用户如何接入、如何使用”，前端 SDK 与后端 SDK 分别讲解，不能把本机运行教程当成主线。
- 传统模式第一篇为产品介绍：一句话说明用途、核心特点、产品形态表格。表格左侧是前端 SDK／后端 SDK，右侧是各自的使用入口，再进入安装与接入教程。

## 实现范围与事实

独立本地文档宿主，复用本仓库 Engine、chat-ui、chat-server。六个只读工具覆盖文档搜索／读取、公开 API 声明、示例查找、公开源码搜索／读取。源码为启动时 Git HEAD 的固定白名单快照，不含未提交改动。凭据继续由已有本地加载器在服务端读取。使用独立数据库，不占用 Playground 的管理锁。当前追加范围不部署、不发布。

产品能力以当前可执行使用文档和导出接口为准。M0–M3 已实现；分布式调度、真实 replay 和监控产品不是首版能力。包尚未发布到公共 npm。

## 设计判断（本任务推定）

AI 对话为默认入口，传统阅读为可切换入口。读者通常在桌面终端与浏览器之间对照操作，默认明亮中性背景，提供深色模式。继承 chat-ui 的白底、深蓝文字、蓝色交互、系统字体与平直分隔线。传统模式采用两条明确的接入路线与渐进式使用手册。

AI 模式使用 mountChatPage；传统模式的总览提供前端和后端接入入口。“询问本文”保留文章位置，打开 mountChatWidget 并填入可编辑问题，由用户发送。模式切换共享会话与同一标签页草稿；来源链接提供文档或带行号的源码。

## 交付与验证

搜索、文章导航、复制代码、目录锚点、主题、移动导航、真实聊天与错误恢复均可操作；验证匿名会话隔离、六个只读工具、路由边界、模式切换、浏览器交互和真实模型。截图及私有运行记录放入忽略目录。本次按 Impeccable 技能显式要求进行独立设计终审与系统记录，结论见验收记录。
