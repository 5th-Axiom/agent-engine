# Agent Engine 官方文档站

## 用户与任务

面向第一次将 Agent Engine 接入自己产品的中文开发者。主线是两条并列接入路线：使用前端 SDK 获得现成 IM，或直接使用后端 SDK 获得 Agent 能力。每条路线说明安装、完整调用、配置、接入后的日常使用和扩展；本地源码演示只作为附录。

## 已确认

- 用户要求可操作的文档站，直接实现后看实际页面调整（code-led）。
- 全站默认接入现有聊天 SDK，点击 icon 打开；允许普通聊天，优先依据项目资料回答。
- 内容要适合初次接入者，兼顾电脑与手机，说明代码放在哪里、哪些是 SDK API、哪些业务函数由接入方实现，以及验证结果。
- 用户明确修正方向：重点为“用户如何接入、如何使用”，前端 SDK 与后端 SDK 分别讲解，不能把本机运行教程当成主线。

## 实现范围与事实

独立本地文档宿主，复用本仓库 Engine、chat-ui、chat-server。只向助手开放公开文档的只读检索。凭据继续由已有本地加载器在服务端读取。使用独立数据库，不占用 Playground 的管理锁。不修改正在审查的核心代码，不部署、不发布、不提交。

产品能力以当前可执行使用文档和导出接口为准。M0–M3 已实现；分布式调度、真实 replay 和监控产品不是首版能力。包尚未发布到公共 npm。

## 设计判断（本任务推定）

Read 为主、Operate 为辅。读者通常在桌面终端与浏览器之间对照操作，默认明亮中性背景，提供深色模式。继承 chat-ui 的白底、深蓝文字、蓝色交互、系统字体与平直分隔线。采用两条明确的接入路线与渐进式使用手册。

首页提供“前端 SDK 接入”和“后端 SDK 接入”两个入口；特色交互为“询问本文”：保留文章位置，打开真实 SDK 并填入可编辑问题，由用户发送。

## 交付与验证

搜索、文章导航、复制代码、目录锚点、主题、移动导航、真实聊天与错误恢复均可操作；验证匿名会话隔离、文档检索、路由边界、浏览器交互和真实模型。截图及私有运行记录放入忽略目录。因本侧对话禁止子代理，设计终审与系统记录由本线程按降级流程完成，并明确披露。
