# Agent Engine 文档站

面向接入方的中文使用手册，默认接入本项目的 IM SDK 和文档助手。包含 25 篇文章，传统模式按用户场景组织，提供后端、前端和全栈三条完整接入路径；支持命中片段与章节搜索、文件名和代码高亮、复制、深浅主题及手机布局。

- 从环境准备开始，选择创建对话、嵌入界面或完整示例；`pnpm example:export` 导出带本地依赖包和配置的三个独立目录。
- 场景覆盖续聊、图片、工具、Skill、知识、记忆、事件、Debug、登录和主题；符号、默认值与授权放在 API 参考。
- 当前交付为源码及本地 SDK 开发包。公共 npm、CLI、压缩包和安装包由 delivery.ts 保留待确定的空位。
- 本地 Playground、私有文件配置和本站启动方式放在附录，不作为接入业务项目的前置步骤。

启动后直接查看 [接入总览](http://127.0.0.1:4320/docs/welcome/)、[前端 SDK](http://127.0.0.1:4320/docs/frontend/) 或 [后端 SDK](http://127.0.0.1:4320/docs/sdk/)。

## 现在就打开

在项目根目录执行。需要 Node ≥ 22.19、pnpm 10.17.1；第一次准备模型和数据库请看根目录的新手文档。

```sh
pnpm install --frozen-lockfile
pnpm run docs
```

打开 <http://127.0.0.1:4320/>，保持终端运行。默认进入 **AI 模式**，直接在页面中的对话框提问。顶部切换到 **传统模式**，继续使用原有的目录、文章和搜索；文章里仍可点击“询问本文”打开右下角助手。按 Ctrl + C 停止本站。

传统模式从“产品介绍”开始，提供“创建对话”“嵌入界面”“完整示例”三个入口，之后按实际任务选择场景。场景代码直接读取经过类型检查的 snippets 源文件。

两种模式共享当前会话和历史；同一标签页切换时保留未发送草稿、当前文章和阅读位置。AI 页的“继续阅读”以及传统模式入口都可返回原位置；移除阅读位置后回到产品介绍。刷新后恢复会话，AI 模式可以查看历史、新建对话、取消回答和重试。直接打开 `/docs/.../` 仍然进入对应文章。模型正在回答时切换模式，已受理的任务在服务端继续运行。

桌面聊天区左侧常驻对话列表，点击条目可切换，当前会话以蓝色标记。顶部的“当前会话”展示会话 ID、创建时间、轮数和配置版本；“工具”展示该会话的实际工具清单、用途及权限类型。手机或窄容器通过左上角按钮展开对话列表，信息面板可滚动查看。传统模式在大于 1000px 的窗口中使用 440px 右侧助手栏，正文让出空间；较窄窗口使用全屏聊天。窄助手栏通过按钮展开会话列表；这些操作全部复用通用 SDK。

站点运行后，可用 `pnpm exec tsx examples/docs-site/smoke-panels.ts` 单独检查两种模式的侧栏和信息面板。它会创建一个匿名空会话并验证保存、刷新恢复，不发送模型请求；真实回答验证使用 `pnpm smoke:docs`。

首次默认启动会在现有本地 PostgreSQL 实例中创建 **agent_engine_docs**。它与 Playground 的 agent_engine_playground、测试的 agent_engine_test 分开，不争用同一个 Engine 管理锁。

还没配置模型和数据库时，可以只阅读：

```sh
pnpm run docs --read-only
```

仅阅读模式仍支持搜索与导航。聊天图标会明确说明未连接，并给出配置步骤，没有伪造的 AI 回复。

## 助手如何工作

- AI 模式使用 `mountChatPage`，传统模式使用 `mountChatWidget`；都通过 `createHttpChatTransport` 与 `createChatHandler` 复用现有聊天 SDK。
- 两种模式在同一标签页共享 5 分钟的列表摘要缓存，首次挂载同步显示、后台校验；服务端根据已验证访客派生 scope，身份变化不恢复旧列表，正文不写入该缓存。`pnpm verify:session-list` 验证慢请求与重开。
- 项目问题先查资料，普通聊天可直接回答。六个工具均为服务端只读 Binding：

| 工具            | 用途                                     |
| --------------- | ---------------------------------------- |
| `docs.search`   | 搜索本站白名单文章的标题、路径和摘要     |
| `docs.read`     | 读取原始 Markdown，保留代码，按行分页    |
| `api.lookup`    | 查公开导出声明片段；完整类型可继续读源码 |
| `examples.find` | 按 API 名或关键词查接入示例、契约测试    |
| `code.search`   | 按关键词查公开源码，可指定目录前缀       |
| `code.read`     | 按精确文件路径、起始行读取索引中的源码   |

- “询问本文”只填写可编辑草稿，不自动发送，也不覆盖已有草稿。切换文章保留当前聊天。
- 回答支持安全 Markdown 和代码复制；原始 HTML 不执行，远程 Markdown 图片不自动加载。两种模式均在对应回答下面提供经过路径白名单校验的资料链接；新标签页打开文档或带提交版本和行号的源码。链接存在不等于答案每句话已获证实。
- 不提供终端执行、文件修改、凭据读取、库存或其他业务工具。

源码来自启动时 Git HEAD 的固定快照，范围为六个包的 `src/`、`examples/docs-site/snippets/` 与 `tests/contract/`、`tests/integration/`、`tests/recovery/`。排除符号链接、私有目录、未跟踪文件和未提交改动。修改源码后需提交并重启才能被检索；文章则在重启时从本地正文更新，用内容摘要标记版本。`api.lookup` 是导出声明定位，不是完整语言服务器或调用图分析。

每次读取最多 70 行、4800 UTF-8 字节，`nextLine` 提示续读；超长单行明确提示改看原文，不伪装成完整内容。搜索结果数量有上限，空结果不代表功能不存在。每轮最多 8 个模型步骤、10 次能力调用、90 秒和 64000 总 Token；提示词引导最多 6 次工具查询，实际成本由模型和问题决定。旧会话在下一次发送时升级工具配置，历史保留，已经受理的运行使用其原有配置快照。

## 模型与私有文件

沿用 `scripts/lib/local-model-config.ts`，从仓库根目录的 `.local/models.json` 和 `.secrets/credentials.json` 读取所选 Profile 的最小凭据集，不另复制密钥。真实调用产生供应商用量。

| 环境变量                     | 默认与含义                                                         |
| ---------------------------- | ------------------------------------------------------------------ |
| AGENT_DOCS_PORT              | 4320；仅监听 127.0.0.1                                             |
| AGENT_DOCS_MODEL_PROFILE     | 集中模型文件里的 default                                           |
| AGENT_DOCS_MAX_OUTPUT_TOKENS | 1536；仅本助手覆盖，允许 256–4096 且小于模型窗口，不改写原 Profile |
| AGENT_DOCS_DATABASE_URL      | 本地 agent_engine_docs；自定义库需预先创建，并与其他 Engine 分开   |

输出上限必须符合所选供应商与模型能力。图片按钮取决于所选模型的视觉能力；配置 `capabilities.images=true` 与 `limits.maxImageInputTokens` 后可通过已有聊天组件发送图片。真实视觉验证范围见[优化总结](../../docs/usage-optimization-summary.md)。正常重启保留原 PROTOCOL_KEY，它同时用于派生本站独立的 Cookie 签名 Key，原始密钥不会发到浏览器。

## 内容维护

文章清单在 content.ts，`content/*.md` 保存按接入任务组织的正文。完整接入与场景示例位于 `snippets/*.ts`，通过正文标记加载，页面显示的代码与 TypeScript 检查的是同一份；需要宿主登录或业务函数的片段会明确说明。docs/sdk-usage.md 与 docs/local-model-configuration.md 作为参考和附录直接同步；页面与助手共享同一份内容，重启后更新。

`render.ts` 通过 Marked 渲染服务端 HTML。外部链接仅允许 HTTP(S)，原始 HTML 作为文本显示，代码转义；静态资源使用精确白名单。源码阅读路由只访问内存中的已提交文件索引，没有通用文件服务器。历史设计、参考项目说明和私有目录不进入检索。

前端通过同源 JSON 读取文章，保留聊天实例；直接打开文章路径仍有完整服务端 HTML。搜索在浏览器完成，不调用模型。不支持 JavaScript 时仍可阅读正文、使用普通导航链接。

## 本地与公网边界

这是完整的本地文档宿主，本次没有部署或发布。匿名访问使用签名、30 天有效的 HttpOnly / SameSite=Strict Cookie 区分浏览器；服务端通过可信主体加载会话，限制 Origin 和 Host。每个访客每小时最多 60 次新建或发送请求，取消不受此额度影响；计数仅保存在当前进程中。Cookie 隔离不等于真实用户登录，同一浏览器配置里的标签页会共享访客身份。

公网部署需要另行接入 HTTPS、正式身份或访客生命周期管理、持久限流/日级预算、数据库备份与数据保留策略。不能把本地匿名宿主直接当成已完成的生产客服网关。普通浏览不产生模型调用，发消息才会。

前端接入教程提供 JavaScript / React / Vue 标签切换，支持左右方向键和带章节锚点的深链接。左侧目录默认展开当前分类，其他分类点击展开。

输入框支持展开编辑、自动增高、快捷键设置、上一条文字找回，以及真实模型/Skill 选择。本站默认 Enter 发送、Shift+Enter 换行；普通 SDK 默认习惯保持 Ctrl/⌘+Enter。启动器读取本地已配置模型 Profile，AGENT_DOCS_MODEL_PROFILE 决定默认项；空闲的本站旧会话会在授权读取时更新可选配置，正在执行的 Run 保持冻结。模型和图片能力独立校验，麦克风因未接入语音识别而置灰。详细 API 与验证见 [输入编辑与模型选择](../../docs/composer-alignment.md)。

聊天回复支持公开思考与平滑流式 Markdown。本地启动显式开启展示，历史未记录的正文无法补回；配置与限制见[回复展示改进](../../docs/reply-display-alignment.md)。
