# ADR 0005：可嵌入的聊天 SDK

用户明确追加前端 SDK：设计 token → 原子组件 → 业务组件 → 页面，支持换肤、改色、PC/移动布局及管理后台图标入口。该范围作为首版后的独立接入能力，不扩大到 M4/M5。

## 接入边界

- `@agent-runtime/chat-core`：浏览器/Node 通用的受限 DTO、HTTP transport 和会话控制器，无 DOM、SDK 或数据库依赖。
- `@agent-runtime/chat-ui`：Tokens、Atoms、Components、Pages 四层；页面组合组件与控制器，业务组件只接收 ViewData 和回调。通过 Shadow DOM 隔离宿主样式；提供悬浮入口和嵌入式聊天页。
- `@agent-runtime/chat-server`：Node HTTP 桥接到公开 Engine。宿主每次请求提供已验证身份下的 Engine 和助手白名单；浏览器只选择助手 ID，不能提交模型地址、凭据、工具或可信身份。

助手归属写入服务器管理的 Session 配置元数据，与会话创建一同持久化。每次列表、读取、发送、取消都重新检查助手仍被授权、所属应用 namespace 和 Engine 的主体权限。正文仅通过明确投影返回，私有 Thinking、原生载荷和凭据不进入协议。请求 ID 在受理结果不明时复用。

## 展示与生命周期

继承现有工作台配色作为默认 Light，补齐 Dark/System 模式及两种圆角/密度皮肤。语义色和几何 token 统一定义，业务组件不写品牌值。图标来自独立编写的统一线性 SVG。桌面为侧边浮动面板，移动端为占满可用视口的对话；容器变化独立驱动嵌入页布局。输入焦点和历史滚动位置保持稳定，更新已有文本不抢走历史阅读位置。

`destroy` 取消浏览器请求、计时器和订阅并卸载 DOM，不假装撤销已经受理的 Run。关闭面板只隐藏，不取消任务。账户切换由宿主销毁并重建实例；可选会话标识缓存必须按账户隔离，默认不写浏览器存储。

## 验证要求

确定性状态/协议测试，HTTP 真实鉴权、CSRF、跨主体、私有数据隔离测试；实际浏览器覆盖主题切换、两种页面、多个实例、宿主样式干扰、输入法、键盘、取消、错误重试、滚动与卸载。最终在独立开发库复用授权模型做接入 smoke；文档明确脚本、SDK 和后端各自责任，不宣称已发布 npm 包。
