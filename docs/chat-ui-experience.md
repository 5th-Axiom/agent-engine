2026-09-12。按用户确认的界面复核直接实施，基于 `main` / `origin/main` 的 `95317e3`；仓库没有 `master` 分支。首轮处理共享 DOM 组件和文档宿主的空间、操作反馈；用户体验后发现的会话切换和响应延迟，追加修复记录见本页末尾。2026-09-13 的小批次出字和服务端批量读取修复见[回复展示改进](reply-display-alignment.md)及 DOCS-61，覆盖下方早期缓冲参数。

| UX-05 | 过程、执行详情重复用量，完成后过程仍先于答案 | 每轮一个过程入口，合并用量、费用完整性和执行记录；完成后置于回答和来源之后 | `verify:chat-process` 验证仅一个可见 Token 汇总、完成后默认收起、主动展开/详情滚动/焦点保留；问题与审批位于折叠区之外，收起过程仍可处理 |
| UX-06 | 文档开窗改变正文宽度，隐藏导航与页内目录 | 开关不改变文章网格；空间足够时右侧并排，否则覆盖，≤800px 全屏原生模态 | `verify:docs` 对比开窗前后正文矩形完全相同，导航保留；1920px 并排不覆盖正文；来源、锚点、返回阅读位置与草稿恢复通过 |
| UX-07 | 侧窗统一上移入场、关闭直接消失；过程高度参与动画 | 新增可选 `panelMode: 'side'`，侧窗从对应边缘轻移、浮窗从下方轻移；反向开关接续当前位置；键盘和减少动态效果即时执行；移除过程高度动画，按钮按压缩至 .97 | `verify:chat-ui` 检查位移方向、中断前后透明度连续、逻辑通知次数、键盘无活动动画、减少动态效果、跨断点模态与关闭中销毁。只动画 transform/opacity，沿用 motionMs，默认 160ms |

调整理由：长期不可用的语音按钮不应占据发送路径。模型名称在最窄容器中允许省略显示，原生选择器和 title 保留全名，输入字体保持 16px，主要按钮和选择器保持 44px。不能把缩小字号作为释放阅读空间的方式。

## API 与维护

`ChatWidgetOptions.panelMode` 为兼容新增，默认 `floating`。`::part(panel)` 仍是宿主定位入口。`isOpen` 和 `onOpenChange` 表示逻辑状态；关闭动画完成后释放原生模态并返回入口焦点，销毁立即释放。输入组件新增可选 `availableHeight` 回调和 `resize()`，单独组合时由宿主通知容器变化。完整用法见 [前端 SDK](frontend-sdk.md)。

过程和审计仍由原有安全投影提供；未知 Token、待结算用量、分币种费用和完整性没有被折算成零或删除。低层 `createRunDetails()` 可独立使用。输入区、过程和挂载层的观察器、动画、计时器与全局监听在销毁时清理。

## 后续会话切换与响应延迟修复

| 编号 | 已确认问题 | 修复与验证 |
| --- | --- | --- |
| RESP-01 | 本地问题完全依赖首次快照，创建/发送/读取期间仍显示欢迎页 | 点击发送同步显示冻结的问题与“正在发送”；确认后清空输入并显示等待回复，只有对应 Run 到达才替换本地消息。合成 HTTP 分别挂起创建、受理与快照；丢失受理、相同编号重试、无重复消息通过 |
| RESP-02 | 切换先清空，中间内容与左侧选中态都等待网络 | 请求的会话立即选中；已浏览会话立即显示缓存并重新验证，首次访问显示加载状态。缓存最多 5 个 / 约 4MiB，纯内存；过期、撤权及销毁清理。快速 A/B 切换的迟到响应不会覆盖当前选择；缓存未验证时禁止发送 |
| RESP-03 | 当前快照和历史列表使用 Promise.all，慢列表拖住显示和下次刷新；旧轮询定时器还可能中断正在切换的读取 | 两条请求独立提交状态；后台历史至少间隔 5 秒且合并请求，活动会话在读取完成后等待 250ms。挂起历史时仍持续收到快照；3 秒慢切换未被定时器打断，失权后停止轮询直到重新连接 |
| RESP-04 | 固定短缓冲赶完一批文字后长时间等待，接收中还重置帧时钟 | 根据到达间隔使用 100–320ms 有界缓冲，保留正在进行的帧时钟，结束最多约 100ms 收尾。持续合成输出产生 129 次 DOM 更新，最大采样间隔 273ms；字素、稳定 Markdown/复制焦点、上翻阅读与减少动态效果通过 |
| RESP-05 | 实际服务的一次快照耗时 3498ms；数据授权与检查反复回读全部会话的 Run | Store 可选 listBySession，PostgreSQL 增加参数化查询及索引，只读当前会话 Run。归属、来源授权、保留检查和事务保持；隔离 PostgreSQL 验证跨主体拒绝、撤权与旧自定义 Store 回退 |
