## 追加：左侧会话与工具面板

`mountChatPage` 与 `mountChatWidget` 共享左侧会话列表及“当前会话”/“工具”入口。宽容器常驻侧栏，窄容器通过按钮展开；详情区可用键盘聚焦与滚动。后端公开投影增加工具目录、会话创建时间和配置版本；正在运行的工具使用本轮配置快照。所有新增协议字段可选，自定义旧传输没有目录时显示未提供。

本次实际通过：类型检查与构建、2 文件 / 14 项后端和控制器测试、19 组 SDK Chromium 检查（页面异常 0）、28 组文档宿主检查。覆盖两会话切换、面板同步、草稿保留、键盘滚动与焦点返回、五宽度布局、工具公开边界及活动运行的配置版本。详细行为卡见[文档站验收记录](../examples/docs-site/ACCEPTANCE.md)。以下全量与供应商记录保留为较早交付的证据，不表示本次重复执行全部矩阵。

## 授权真实模型和 PostgreSQL

通过 `/embed/` 使用本机集中配置，未把模型 Key 放入浏览器或示例源文件：

1. 普通 DeepSeek 助手完成真实问答。
2. Thinking 助手通过真实 Anthropic-compatible 路径调用 `demo.inventory`，回答 DEMO-1 合成库存 24 件；工具成功且 Usage 完整。
3. 浏览器 HTTP 投影没有 `native`、`encrypted`、`signature`、`apiKey`、`secretRef` 字段；Debug 独立窗口显示对应工具记录。
4. 停止并重新启动本地服务后，从独立 PostgreSQL 开发库恢复相同 SDK 会话。
5. 继续询问原库存加 1，返回 25，没有再次调用库存工具；浏览器错误 0。

这些结果是本 SDK 接入路径的真实验证。供应商异常、丢回包等情况由确定性契约测试覆盖，不把一次真实 smoke 当成所有异常路径的证明。私有脚本及只含测试结果/会话 ID 的报告保存在忽略的 `.local/` 中；公开记录不包含原生协议载荷或密钥。
