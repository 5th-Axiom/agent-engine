# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

管理后台的开发者需要嵌入通用聊天入口；后台使用者通过入口图标打开 IM，在当前工作环境里和 Agent 对话。用户明确要求 PC 与移动端布局、换皮肤、改颜色。

## Product Purpose

将已有模型聊天能力作为可安装、可组合的前端 SDK 提供。悬浮入口与嵌入式页面共享展示组件和状态控制器，前端不持有模型密钥。

## Operating Context

参考 alice 的设计 Token、原子组件、业务组件、页面分层与 ViewData/回调边界，仅参考结构，不搬运其私有代码、素材或会话。项目已有本地 Playground 和只读 Debug；本轮在管理后台示例中展示 SDK 接入。

## Capabilities and Constraints

具备图文对话、流式快照、工具状态、用量、续聊、历史、取消和错误恢复。设计 Token 与身份认证 Token 为不同概念。模型和工具授权由服务器决定；宿主提供已验证身份。使用框架无关 DOM/Shadow DOM 挂载接口，业务组件通过回调接入数据。通用文件、语音、群聊、分布式调度和生产重放未提供。

用户追加图片：支持选择、粘贴、拖拽、预览、移除与失败重试，发送前完成上传；每条最多 8 张、单张 5 MiB。图片从鉴权接口读取，临时预览在切换与销毁时释放，不在浏览器持久化未发送图片草稿。助手正文支持安全 Markdown、代码复制与白名单来源链接，原始 HTML 不执行，远程 Markdown 图片不自动加载。未启用图片或所选模型没有视觉能力时不提供可用的上传动作。

用户追加要求：对话列表放在聊天区左侧，并提供当前会话及已接入工具的查看入口。页面挂载与悬浮入口共享这些能力；窄容器以可展开侧栏呈现。工具信息采用服务器的公开投影，不读取或显示完整模型／执行器配置。

## Brand Commitments

继承 Agent Engine 已有白色工作面、深蓝文字和清晰操作的开发工具语气。用户授权本 SDK 支持可替换皮肤及品牌色；这些能力不改变现有 Debug 的视觉身份。

## Evidence on Hand

现有 Playground、确定性模型与真实 PostgreSQL 验证设施、已授权本地 DeepSeek 配置。后台示例只使用合成数据。

用户追加 WorkBuddy 式过程展示：每轮过程按服务器真实事件排列，覆盖模型活动、Skill、工具、知识/记忆、重试、等待与上下文整理；输入/结果摘要由宿主显式开放。活动时展开，完成时默认收起，主动查看时保持展开；历史可以再次展开。保留展开状态和正文焦点，显示累计活动时间、实际用量与有依据的估算费用。私有思考正文、原生块与凭据不进入浏览器；未发生的活动不补造。等待问题留在过程折叠之外；宿主开放 interaction 并提供安全请求标识及 schema 时，原生问题、结构化表单与允许一次／拒绝操作通过 resolveInput 继续同一 Run。未提供解析回调或请求标识时保留由接入方处理的说明。

用户追加输入编辑与模型选择：保留原生 textarea，自动增高、就地展开与 Esc 收起、选区和撤销/重做、中文输入法保护、两种发送快捷键、空输入 ↑ 找回上一条文字。工具栏读取服务端实际模型与 Skill 目录，选择只用于下一轮；在已提交请求结果未明时冻结。图片随模型能力启用，不丢弃不兼容草稿。ASR 未接入，麦克风置灰且说明原因。通用 SDK 缺省 Ctrl/⌘+Enter，文档站显式使用 Enter；前端选择和快捷键偏好不跨刷新保存。主要操作已验证，未宣称当前 WorkBuddy 全量功能或 iOS 真机软键盘已验证。


回复展示补充：模型与宿主显式许可、保留策略允许时，展示供应商实际返回的公开思考内容，摘要与正文语义分开。默认关闭，签名与遮蔽块不进浏览器。文档站本地配置已显式开启；旧未保留内容不能补回。保留原生工作界面，当前阶段、思考与工具更突出，已结束基础状态收进执行详情。Markdown 保留节点，接收到的文字短时逐帧呈现；历史立即显示、重试草稿立即撤回，减少动态效果及后台页面停用缓冲。用真实事件与供应商返回值展示过程，不补造未发生的思考或动作。


会话配置追加：IM 顶部“配置”在新标签页打开当前会话的网页；首条消息前打开只创建空会话、保留草稿。四类为工具、Skill、知识与记忆、回答与上下文，支持搜索、逐项开关、明确保存及恢复助手默认。只收窄宿主已接入能力，保存用于后续 Run，活动 Run 保持冻结；记忆读写独立，关闭读取不清空当前聊天记录。未接入能力提供禁用/空状态及文档。版本冲突与网络错误保留草稿；明确失权清掉旧目录并禁用操作，成功重读后恢复。桌面左侧分类，手机两列分类加独立滚动内容区和底部操作；延续既有明暗主题、系统字体与原生控件。

原生待处理输入追加：`createPendingInput` 由过程组件、时间线和页面组合复用，简单字段使用 textarea、select、checkbox 或 number input，复杂 schema 使用 JSON 输入；同一请求在快照轮询时保留原生节点与未提交内容。提交中禁用控件，错误保留可修正状态，过期明确提示；审批范围和最终校验由服务端决定。客户端不能创建能力或提升权限。

文档宿主 `/ai/capabilities/` 是现有工作台的 Operate 扩展，提供能力目录、长期记忆、十三项确定性真实 SDK 实验、身份范围内的会话调试与生命周期操作四个锚点入口。页面导航、记忆存储与实验执行属于宿主，复用共享聊天、设置及待处理输入组件。标准启动器在 PostgreSQL 上声明八个只读工具（六个 binding、实际本地 HTTP 目录与 Streamable HTTP MCP 检索）、inline integration-guide、版本／hash 固定的 loader troubleshoot、正式 KnowledgeBase manual，以及经用户确认、版本 CAS、加密持久化、到期清理和无内容版本 tombstone 的访客偏好记忆。通用 SDK 不默认安装这些能力。

本轮交接验证为 38 文件／192 项（含独立 PostgreSQL 与崩溃测试；全量源码检查显式排除并行任务的 .local 验证副本）、十二张确定性浏览器截图与六次合成对话请求，无浏览器错误；另有已授权真实供应商四个 Run 验证获准记忆写入后新 Session 回读、两项 Skill、知识库、HTTP 与 MCP，标准启动器重启后的 PostgreSQL 记忆回读也已通过。实验每次使用独立 MemoryStore、合成模型和数据，报告保存到宿主 Store，不调用外部模型；实验通过不代表完整供应商或崩溃验证。401／403、迟到响应与生命周期焦点恢复专项已通过，这些行为属于能力宿主的实现，详见其 [验收记录](../../examples/docs-site/ACCEPTANCE.md)。该扩展沿用现有视觉世界，没有新视觉稿；ASR、CLI 分发、分布式调度和真实 replay 仍未交付。
