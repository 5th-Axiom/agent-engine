# Agent Engine Debug

面向维护嵌入式 Agent Engine 的开发者，主要任务是从 Session 查找 Run，再定位失败的 Step、Attempt、操作账本和用量。首版只读，不提供模型/工具重放，不建立第二套事实源。技术方案 §5.16 已确定上述信息结构及状态要求。

浏览器界面用于桌面日常排错，窄屏仍可读取。默认只显示契约摘要、标识符和错误码，隐藏 Prompt、Tool Result、Secret 引用及原生 Thinking。产品事实来自真实 Engine 查询。

本次按用户明确的持续实施指令直接建设，不额外要求审批视觉方案。界面采用朴素的开发运维工作台：表格、查询、展开明细。无品牌或营销要求。
